\section{What FoamWaveTank is}
\fwt{} is a numerical wave tank for OpenFOAM v2506 (openfoam.com) built on top of the
\wtwof{} toolbox~\cite{jacobsen2012wave}. It keeps the \wtwof{} relaxation zones, wave
theories and utilities, and adds:
\begin{itemize}
  \item coupling to the Higher-Order Spectral (HOS) wave solvers HOS-NWT and HOS-Ocean
        through the Grid2Grid library~\cite{choi2019grid2grid,aliyar2022numerical}, so that
        nonlinear, phase-resolved wave fields from HOS can be imposed in the CFD domain
        (Chapter~\ref{ch:hos});
  \item ocean currents, alone or superposed on the HOS waves, with constant, depth-varying
        or parabolic profiles;
  \item the \app{waveIsoFoam} solver, which uses the geometric isoAdvector interface
        scheme instead of MULES (Chapter~\ref{ch:solvers});
  \item floating bodies with FloatStepper~\cite{roenby2024robust}, through the solvers
        \app{floatStepper} and \app{floatStepperWaveIsoFoam};
  \item moorings with MoorDyn~\cite{aliyar2022numerical,chen2022cfd,hall2015validation}, both for FloatStepper and
        for OpenFOAM's own \kw{sixDoFRigidBodyMotion} solver;
  \item an installation script that checks the computer it runs on, reports missing
        prerequisites and verifies the result (Chapter~\ref{ch:install}).
\end{itemize}

\section{How to cite}
\label{sec:cite}
If you use \fwt{}, please cite the HOS--OpenFOAM--MoorDyn coupling
paper~\cite{aliyar2022numerical} and \wtwof{}~\cite{jacobsen2012wave}. In addition, cite
\begin{itemize}
  \item FloatStepper~\cite{roenby2024robust} when you use \app{floatStepper} or
        \app{floatStepperWaveIsoFoam};
  \item the HOS--OpenFOAM--MoorDyn coupling~\cite{aliyar2022numerical}, the MoorDyn--OpenFOAM
        coupling~\cite{chen2022cfd} and MoorDyn~\cite{hall2015validation} when
        you use moorings;
  \item HOS-NWT~\cite{ducrozet2012modified} or HOS-Ocean~\cite{ducrozet2016hosocean}, and
        Grid2Grid~\cite{choi2019grid2grid}, when you use HOS wave fields.
\end{itemize}
The file \file{CITATION.cff} in the repository holds the same references; GitHub shows them
under ``Cite this repository''.
